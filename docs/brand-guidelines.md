# LocalMint Brand Guidelines

## Brand Identity

### Mission Statement
"Rooted in Local. Grown with Purpose." - LocalMint empowers sovereign learning through Bitcoin-native education, fostering local communities while building global knowledge.

### Brand Values
- **Sovereignty**: Individual ownership and control
- **Growth**: Continuous learning and development  
- **Community**: Local connections with global impact
- **Authenticity**: Genuine, transparent interactions
- **Innovation**: Cutting-edge Bitcoin technology

## Visual Identity

### Logo System

#### Primary Logo
- **Usage**: Main brand identifier
- **Formats**: SVG (preferred), PNG with transparency
- **Minimum Size**: 24px digital, 0.5" print
- **Clear Space**: 1x logo height on all sides

#### Logo Variations
1. **Primary**: Full color on dark backgrounds
2. **Light**: Adapted for light backgrounds  
3. **Horizontal**: Logo + wordmark for headers
4. **Minimal**: Single letter "L" for small spaces
5. **Monochrome**: Single color for special applications

#### Logo Don'ts
- ❌ Don't stretch or distort
- ❌ Don't change colors arbitrarily
- ❌ Don't add effects or shadows
- ❌ Don't place on busy backgrounds
- ❌ Don't use below minimum size

### Typography

#### Font Hierarchy
1. **Unica One** - Headings, display text
   - Weights: Regular (400)
   - Usage: H1-H4, brand elements, emphasis

2. **Inter** - Body text, UI elements
   - Weights: Light (300), Regular (400), Medium (500), Semibold (600), Bold (700)
   - Usage: Paragraphs, buttons, navigation, forms

3. **Kuxirious** - Decorative accents
   - Weights: Regular (400)
   - Usage: Special callouts, artistic elements

#### Type Scale
- **H1**: 4xl (36px) / 6xl (60px) desktop
- **H2**: 3xl (30px) / 4xl (36px) desktop  
- **H3**: 2xl (24px) / 3xl (30px) desktop
- **H4**: xl (20px) / 2xl (24px) desktop
- **Body Large**: lg (18px)
- **Body**: base (16px)
- **Body Small**: sm (14px)
- **Caption**: xs (12px)

### Iconography

#### Style Guidelines
- **Style**: Outline with 2px stroke weight
- **Corners**: Rounded (4px radius)
- **Size**: 16px, 20px, 24px, 32px grid
- **Color**: Match text color or use brand colors

#### Icon Library
- **Bitcoin**: ₿, ⚡ (Lightning), 🔗 (Blockchain)
- **Learning**: 📚, 🎓, 💡, 🧠
- **Community**: 👥, 🤝, 🌍, 🏠
- **Growth**: 🌱, 📈, ⭐, 🏆

### Imagery

#### Photography Style
- **Tone**: Warm, authentic, diverse
- **Subjects**: Real people learning, collaborating
- **Settings**: Local communities, natural environments
- **Treatment**: Natural lighting, minimal processing

#### Illustration Style
- **Approach**: Clean, modern, friendly
- **Colors**: Brand palette with supporting neutrals
- **Elements**: Geometric shapes, organic curves
- **Metaphors**: Growth, connection, building

### Layout & Spacing

#### Grid System
- **Desktop**: 12-column grid, 24px gutters
- **Tablet**: 8-column grid, 20px gutters  
- **Mobile**: 4-column grid, 16px gutters

#### Spacing Scale (8px base)
- **4px**: Tight spacing
- **8px**: Small spacing
- **16px**: Medium spacing
- **24px**: Large spacing
- **32px**: XL spacing
- **48px**: XXL spacing

## Voice & Tone

### Brand Voice
- **Knowledgeable**: Expert but approachable
- **Encouraging**: Supportive and motivating
- **Authentic**: Genuine and transparent
- **Innovative**: Forward-thinking and creative

### Tone Variations
- **Educational Content**: Clear, structured, patient
- **Community Posts**: Friendly, inclusive, celebratory
- **Technical Docs**: Precise, detailed, helpful
- **Marketing**: Inspiring, confident, value-focused

### Writing Guidelines
- Use active voice
- Keep sentences concise
- Avoid jargon (explain when necessary)
- Include calls-to-action
- Celebrate achievements
- Encourage experimentation

## Application Guidelines

### Digital Applications
- **Website**: Responsive design, fast loading
- **Mobile App**: Touch-friendly, offline capable
- **Social Media**: Consistent profile imagery
- **Email**: Clean templates, clear hierarchy

### Print Applications
- **Business Cards**: Minimal, professional
- **Stickers**: Fun, shareable designs
- **Merchandise**: Quality materials, subtle branding

### Environmental
- **Signage**: Clear, readable from distance
- **Booth Design**: Welcoming, interactive
- **Workspace**: Inspiring, collaborative
